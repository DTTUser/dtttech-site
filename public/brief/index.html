Part one: what the job actually is

You asked whether Claude can build you a website you then populate with your own material. It can, and I have done exactly that for my own site. It is worth being straight about what the process involves, because the writing-the-website part is the quick bit and everything either side of it is not.

What you would be signing up to run

The site itself is simple. The machinery underneath it is four separate accounts that have to be connected to each other correctly, and that is where the time goes:

AccountWhat it doesCost
LovableThe AI that writes the siteFree tier, or about $20/month
GitHubStores the code and republishes the site automatically every time it changesFree
Amazon Web ServicesActually hosts the site, serves it worldwide, and issues the security certificateUsually under £2/month
A domainYour web address£10 to £15/year

So roughly £250 a year at the outside, most of it the Lovable subscription, which you can cancel between builds. It is cheap to run. It is not effortless to set up.

The honest version. Stages 1 to 3 are genuinely enjoyable and you would be fine at them. Stage 4 is where people give up. It involves storage buckets, a content delivery network, DNS records, a security certificate, and a set of access keys that have to be created with exactly the right permissions and pasted into exactly the right place. None of it is difficult. All of it is unforgiving about detail, and when it goes wrong the error messages are unhelpful.
